Behind the Scenes

Colophon

How this site is built — the tools, fonts, and technologies that make it work.

🎨 Design

  • Palette: Charcoal, Cream, Copper, Slate
  • Typography: DM Serif Display (headings) + DM Sans (body)
  • Icons: System emoji + SVG icons
  • Theme: Dark mode with light mode toggle

💻 Frontend

  • HTML5 / CSS3 / JavaScript — Vanilla (no frameworks)
  • Responsive: Mobile-first, fully responsive
  • Print Styles: Custom @media print rules for PDF export
  • Fonts: Google Fonts (DM Serif Display, DM Sans)

📦 Data

  • Recipes: 118+ JSON files in /data/recipes/
  • Index: Auto-generated recipe index
  • Ingredients: 200+ ingredient database with nutrition
  • Storage: Local file system (no cloud database)

🛠️ Tools

  • Editor: VS Code + Live Server
  • Version Control: Git
  • Validation: JSONLint, W3C Validator
  • Inspiration: Old cookbooks and kitchen notebooks

📐 Features

  • Search: Full-text + ingredient-based
  • Scaler: Recipe scaling calculator
  • Print: Optimised print layouts
  • Cook Mode: Step-by-step cooking assistant
  • Shopping List: Dynamic ingredient list generator
  • Nutrition: Automatic calculation from database
  • Recipe Builder: JSON editor with validation

📝 Credits

  • Recipes: Adapted from family recipes, cookbooks, and kitchen experiments
  • Nutrition Data: Compiled from USDA, Australian Food Composition Database, and kitchen testing
  • Idea: A digital notebook to preserve recipes that work
  • Built with: ☕ Coffee, 🍪 Biscuits, and 🧠 Patience
